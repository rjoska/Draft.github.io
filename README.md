My goal for this project is to make the first version of a simple client-side web app where users can quickly and easily perform a type of draft to meet their needs. From snake drafts to drafts with point limits, this website should be able to handle them all. The main goals for this version are to implement all the different draft types and then allow users to download the draft to store on their personal devices. The file can then be uploaded back onto the site if changes need to be made, such as substitutions (this can be limited), or just for viewing purposes rather than an MD file or txt (not sure which to use yet). The last goal I have is for people to be able to make spreadsheets with a specific format that can be uploaded and parsed for the fast importing of players
